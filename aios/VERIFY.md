## 3. OpenSSL flag confirmation (direct, outside the suite)

Confirmed `pkeyutl -verify -rawin` against the installed binary before relying
on it — a good signature verifies (exit 0) and a tampered message is rejected
(exit 1):

```
$ openssl pkeyutl -sign  -inkey k.pem   -rawin -in m  -out m.sig ; echo sign=$?
sign=0
$ openssl pkeyutl -verify -pubin -inkey pub.pem -rawin -in m  -sigfile m.sig
Signature Verified Successfully
$ echo verify=$?
verify=0
$ openssl pkeyutl -verify -pubin -inkey pub.pem -rawin -in m2 -sigfile m.sig
Signature Verification Failure
$ echo badverify=$?
badverify=1
```

```
$ openssl version
OpenSSL 3.0.13 30 Jan 2024 (Library: OpenSSL 3.0.13 30 Jan 2024)
```
